# loopy-controller-mod-dpad
Maps the analog stick on PSX, N64, GameCube, and Wii to the d-pad on Loopy's controller mod. Replace the files in the original with these. Set Build Configuration to Release, then Build > Clean and Build. Flashing instructions in the archive link.

SNES file included because Home is unmapped. Home button is unmapped on all of them since this is meant for DS controller mods.

Original files: https://archive.org/details/loopys-controller-mod
